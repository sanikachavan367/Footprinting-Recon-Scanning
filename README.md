# Footprinting-Recon-Scanning
Performed footprinting, reconnaissance, DNS enumeration, and network scanning using WHOIS, theHarvester, recon-ng, and Nmap.

# WHOIS
WHOIS is a protocol and command-line tool used to retrieve information about a domain name or IP address registration from public databases.
It helps identify:
1. Domain owner (if public)
2. Registrar details
3. Registration and expiry dates
4. Name servers
5. Administrative/technical contacts
   
# nslookup

nslookup is a command-line network administration tool used to query the Domain Name System (DNS). It helps users find the IP address of a domain name or retrieve DNS records of a website.

# theHarvester
Objective:
The objective of using theHarvester is to gather publicly available information about a target domain from multiple online sources. It is mainly used during the reconnaissance phase of cybersecurity assessments and penetration testing.

The tool helps collect:
1. Email addresses
2. Subdomains
3. Hostnames
4. Employee names
5. Open ports and services
6. Publicly available information from search engines and databases

#  recon-ng
Objective:
The objective of using Recon-ng is to perform Open-Source Intelligence (OSINT) gathering and reconnaissance on a target domain, organization, or individual. The tool automates information gathering from multiple public sources to assist cybersecurity professionals during penetration testing and security assessments.

Recon-ng helps collect:
1. Domain information
2. Subdomains
3. Email addresses
4. IP addresses
5. Employee details
6. DNS information
7. Social media and public records

# Nmap Tool
Objective:
The objective of using Nmap (Network Mapper) is to perform network discovery and security auditing. The tool is used to identify active hosts, open ports, running services, operating systems, and possible vulnerabilities in a network.

Nmap helps in:
1. Host discovery
2. Port scanning
3. Service version detection
4. Operating system detection
5. Vulnerability assessment
6. Network inventory and monitoring
   
# Conclusion
The use of Nmap, theHarvester, Recon-ng, and nslookup successfully demonstrated various reconnaissance and network analysis techniques.

These tools helped identify:
1. Active hosts
2. Open ports and running services
3. DNS records and IP addresses
4. Subdomains and email addresses
5. Possible security weaknesses

The analysis highlighted the importance of regular security monitoring, vulnerability assessment, and protecting publicly exposed information. The practical use of these tools improved understanding of network reconnaissance, information gathering, and cybersecurity assessment techniques.

# Footprinting-Recon-Scanning
Performed footprinting, reconnaissance, DNS enumeration, and network scanning using WHOIS, theHarvester, recon-ng, and Nmap.

# * WHOIS Lookup
Objective:-<br>
 WHOIS is used to gather registration information about a domain such as owner details, registrar, DNS servers, and creation/expiry dates. <br>
Command:-<br>
 whois google.com <br>
Explanation:-<br>
  - whois → Queries WHOIS databases <br>
  - whois → Queries WHOIS databases  <br>
  - example.com → Target domain <br>
Sample Output:- <br>
  Domain Name: example.com <br>
  Registrar: Example Registrar Inc. <br>
  Creation Date: 2020-01-01 <br>
  Expiry Date: 2030-01-01 <br>
  Name Server: ns1.example.com <br>
Analysis:- <br>
  The WHOIS results reveal: <br>
    Domain registrar information <br>
    Registration timeline <br>
    DNS server details <br>
    Administrative and technical contacts (if public) <br>
